## What YazSes is

Local, offline hold-to-talk voice dictation for **Linux (X11 & Wayland), macOS and
Windows**. Hold a key, speak, release — your words are transcribed on your own CPU
with [faster-whisper](https://github.com/SYSTRAN/faster-whisper) and typed into
whatever app has focus. No cloud, no API key, no subscription, no telemetry.
Apache-2.0.

It also transcribes recordings offline and can capture a whole meeting with speaker
names and generated minutes — entirely on-device.
